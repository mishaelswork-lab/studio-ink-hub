# ArtSpace Connect

Build a tattoo artist booking platform called "ArtSpace" with THREE interfaces:

CUSTOMER APP:

- Phone OTP login

- Browse studios by location

- View artist portfolios  

- Book appointments (₹500 cover charge)

- Pay via Razorpay

- AI tattoo style consultant

ARTIST DASHBOARD:

- Login with username/password

- View/accept/reject bookings

- Upload portfolio images

- Set availability

- Track earnings

ADMIN PANEL:

- Login: admin/admin123

- Add/manage artists

- View all bookings

- Analytics dashboard

DESIGN:

- Dark theme: bg #09090c, gold #c9a96e

- Fonts: Cinzel (headings), DM Sans (body)

- Premium, elegant feel

TECH:

- Next.js + React + TypeScript + Tailwind

- PostgreSQL database

- Razorpay payments

- AWS S3 for images

- Google Gemini for AI (free)

- Firebase Auth for OTP

Include sample data: 5 studios in Bengaluru, 6 artists with different specialties.

Make it fully responsive and production-ready.
